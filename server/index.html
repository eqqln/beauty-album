安装说明 照这个顺序来，一次装好

方式一 · 直接安装 最快

1
用 Safari 打开本页。在微信里打开无法安装，请点右上角「在浏览器中打开」。
2
点右侧「立即安装到 iPhone」，弹窗里选「安装」。
3
回到桌面等待图标下载完成，图标出现后再点开。
4
若提示「未受信任的开发者」，去 设置 → 通用 → VPN与设备管理 里点信任该证书。

方式二 · 电脑自签安装 未签名包

1
先点「下载安装包（.ipa 文件）」，把包存到电脑。
2
电脑装 Sideloadly 或 AltStore，用数据线连上 iPhone。
3
把你的 Apple ID 填进去，选择刚下载的 .ipa，点开始签名安装。
4
系统支持的话，TrollStore 可以直接安装，不需要电脑。

常见问题

点了安装没反应 / 转圈后消失

多半是在微信、QQ 里打开的。请复制网址到 Safari 里重新打开。仍不行就长按「立即安装」按钮，选「在新标签页打开」。

提示「无法安装此 App」

说明这个包还没有企业签名。请改用方式二，用电脑自签安装；或者联系管理员换成已签名的包。

打开闪退

先确认系统是 iOS 16.0 以上。如果刚装完就闪退，删掉重装一次；自签的包证书过期也会闪退，重新签一次即可。

怎么登录 App

用手机号收验证码注册，然后设置密码登录。套餐、充值卡都在 App 里「我的」页面操作，充值卡号卡密由店铺后台生成后发给你。
