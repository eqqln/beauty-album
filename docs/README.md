## 一句话结论

原来后台 17 个模块里，IPA 只联动了 3 个（套餐/会员/充值钱包），其余 12 类业务数据全在手机本地，两边各存一份互不相干。现在通过 `uid` 主键映射 + 双向同步引擎，客户、照片、步骤、笔记、收款、领用、导师、产品、代理、拿货、预约全部打通，改一边另一边刷新即可见。

## 快速开始

**后台**：`https://meiyan.shengka.net/admin/` → `admin@meiyan.local` / `Meiyan@2026`

**手机**：装 1.6.0 包 → 第一屏输入激活码 + **使用人姓名 + 手机号** → 激活成功后自动开一块独立板块并接管同步，不用再手动登录店铺账号

**开新板块**：后台「系统 → 激活码」生成一张码 → 发给客户 → 对方激活时填自己的姓名电话，后台「系统 → 板块管理」里就会出现他那一块

**换手机**：装 1.6.0 → 输入同一张码（姓名电话自动带出）→ 后台「板块管理」点「恢复」→ 手机下次打开会提示整份拉回

**加员工**：后台「系统 → 员工管理」→ 新建 → 选角色（店主/店长/美容师/前台/只读）→ 需要更细就勾模块和特殊能力

**改网址显示**：后台「系统 → 系统设置 → 网址显示方式」→ 加密（默认）/ 明文

**备份某一块板**：后台「系统 → 板块管理」→ 找到那个人 → 点「⬇ 备份下载」→ 得到一个 zip，里面是他的客户、相册、步骤、预约、产品、会员、收款、充值卡、授权记录，加上全部图片视频，和 17 份能直接用 Excel 打开的中文 CSV
