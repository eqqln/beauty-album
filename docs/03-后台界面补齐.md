# 03 · 后台界面补齐

> 目标：后台能直接管理 App 端同步上来的四类数据，并在概览页一眼看到同步状态。
> 涉及文件：`server/admin/js/schema.js`、`server/admin/js/crud.js`、`server/admin/js/app.js`、`server/admin/css/app.css`

## 一、新增四个菜单

`app.js` 的 `NAV` 在「服务」分组下插入：

| 菜单 | 路由 | 图标 | 说明 |
|---|---|---|---|
| 预约 | `m:appointments` | 📅 | App 排期同步，改一边两边都变 |
| 护理步骤 | `m:steps` | ✅ | 疗程步骤与完成情况 |
| 客户笔记 | `m:notes` | 📔 | App 里记的文字笔记 |
| 产品领用 | `m:claims` | 🏷️ | 客户用了哪些产品 |

「服务」分组现在是 9 项，顺序：

```
客户 → 预约 → 护理步骤 → 客户笔记 → 产品领用
     → 相册图片 → 对比图 → 导师 → 产品
```

> 顺带把 4 个兼容性差的 emoji 换掉了：`🪜`(U+1FA9C, Emoji 13) `🖼`(需 VS16) `↔️` `🧴` 在 Windows 10 / 部分安卓上会显示成方块。换成 `✅ 📔 🏷️ 📷 🔀`，都是 Emoji 1.0。

## 三、`crud.js` 的三处扩展

### 3.1 `ref` 支持按 `uid` 取值

原来的 `ref` 下拉只能按 `id` 取值，遇到 UUID 关联就废了。加 `valueKey`：

```js
} else if (f.type === 'ref') {
  var vk = f.ref.valueKey || 'id';
  var cur = String(values[f.k] ?? '');
  control = '<select data-k="' + f.k + '">...' +
    opts.map(function (o) {
      var val = o[vk] == null ? '' : String(o[vk]);
      return '<option value="' + UI.esc(val) + '"' +
             (val === cur ? ' selected' : '') + '>' + ... + '</option>';
    }).join('') + '</select>';
}
```

### 3.2 列表单元格显示父级名字

`ref` 字段在表格里原来显示 `#17`。加 `showKey`，有回填的人名就直接显示人名：

```js
if (f.ref) {
  if (f.ref.showKey && row[f.ref.showKey]) return UI.esc(row[f.ref.showKey]);
  if (!v) return '<span class="td-sub">—</span>';
  return '<span class="td-sub">#' + UI.esc(v) + '</span>';
}
```

配合后端 `list` 接口回填的 `client_name`，预约列表的「客户」列显示「测试客户A」而不是一串 UUID。

### 3.3 `select` 支持 `{v,t}` 选项

数字型枚举（`done: 0/1`、`claimed: 0/1`）需要「存数字、显示文字」：

```js
var val = (o && typeof o === 'object') ? o.v : o;
var txt = (o && typeof o === 'object') ? o.t : o;
```

同时 `badge` 渲染也做了反向查找，`0` → 「未完成」、`1` → 「已完成」。

## 四、概览页同步面板

`renderOverview()` 在统计卡片下方插入一块：

```js
html += '<div class="section-head"><h3>App 数据同步</h3><div class="sp"></div>' +
        '<span class="td-sub" id="syncHint">正在读取…</span></div>';
html += '<div class="card sync-panel" id="syncPanel">' +
        '<div class="sync-grid" id="syncGrid"></div></div>';
```

`loadSyncPanel()` 调 `sync/stats`，把 12 个模块的条数铺成网格：

```js
var LABELS = {
  customers:'客户', photos:'照片', compares:'对比', payments:'收款',
  steps:'护理步骤', notes:'笔记', claims:'产品领用',
  teachers:'导师', products:'产品', agents:'代理',
  agent_orders:'拿货', appointments:'预约'
};
```

条数为 0 的格子加 `.zero` 变灰，一眼能看出「哪类数据还没上云」。

### 样式

```css
.sync-grid{display:grid;grid-template-columns:repeat(6,1fr);gap:10px}
.sync-cell{background:var(--cream);border:1px solid var(--line);
           border-radius:11px;padding:10px 12px;text-align:center}
.sync-cell.zero{opacity:.45}
.sync-cell .sc-k{font-size:11.5px;color:var(--muted);font-weight:600}
.sync-cell .sc-v{font-size:19px;font-weight:700;color:var(--rose-deep);margin-top:3px}
```

响应式：900px 以下 4 列、720px 以下 3 列、460px 以下 2 列。
